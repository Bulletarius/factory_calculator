# Factory Calculator
an app to help you calculate your factories in eny game.
## How to use
Simply create the recipes, inputs and outputs then look at the graph
### Creating recipes
Click on the recipes menu then click add recipe. You should see a window split
into three parts. The top and middle parts serve as the recipe itself
with the top being shown in items per second and the middle in time taken per
recipe. These parts auto update when changing things in the other part.

The bottom part contains buttons like remove ingredient, remove product,
add ingredient and add product. These buttons add or remove components for
products and ingredients. The first text field is to add items to the app
to use them elsewhere. Confirm with enter or the add item button. The second
text field is the name of the recipe / building it is made in. The delete
and save button is used to save or cancel the creation of the recipe.

**Do not make recipes that have the same product as an input of a recipe**
### Creating inputs and outputs
Click on the input/output menu the click add input or output. The combo box
selects which item it is about. All outputs should be a goal and all
inputs should not be a goal. The number represents how much items the factory
should produce.
### Reading the graph
Should be pretty self-explanatory but sometimes the graph is a bit messed up.
It generally should go from top to bottom and when it hits the end it should
go sideways, but sometimes it is better to look at the items and see how the
items connect yourself.

**If it seems like the nodes have duplicated resize the window to update it**
